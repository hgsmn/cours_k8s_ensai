# Fiche d'évaluation

Formation ENSAI · Docker & Kubernetes · 2026

L'évaluation repose sur **deux éléments**, répétés à chaque TP :

| Élément | Quand ? | Ce qui est évalué |
|---|---|---|
| **Compte rendu de TP** (écrit) | À rendre à l'issue de chaque TP | Ce que vous avez fait, comment, et avec quel résultat |
| **Questions orales** | À la fin de chaque TP | Votre compréhension des notions abordées |

---

## 1. Les comptes rendus de TP

Chaque TP donne lieu à un compte rendu, rédigé selon le formalisme ci-dessous. Il n'est pas nécessaire d'être long : une liste de bullet points peut suffir. 

### Formalisme imposé

#### 1. Ma procédure

Vos réflexion pour réussir le TP. 

#### 2. Mes difficultés éventuelles

Décrivez les problèmes rencontrés :

- le message d'erreur ou le comportement inattendu ;
- la solution trouvée, ou ce qui reste bloquant.

> Une difficulté bien analysée vaut autant qu'un TP réussi du premier coup. Ne la cachez pas.

#### 3. Mes remarques

- ce que vous avez retenu du TP ;
- les améliorations possibles (pour votre déploiement ou pour le TP lui-même).

---

## 2. Les questions orales

À la fin de chaque TP, quelques minutes d'échange pour vérifier l'acquisition des compétences visées.

- Les questions portent sur les **notions du TP** : *pourquoi* cette commande, *à quoi sert* cet objet, *que se passe-t-il si*…
- Pas de piège : l'objectif est de vérifier que vous savez **expliquer** ce que vous avez déployé.
